# Smart Device Price Analytics with AI Recommendation

## Project Overview

This project analyzes laptop and smartphone datasets using machine learning
techniques for price analytics and recommendation.

## Machine Learning Tracks

- Regression
- Classification
- Clustering

## Regression

Laptop price prediction using multiple regression algorithms including
Linear Regression, Ridge, Lasso, ElasticNet, Polynomial Regression,
Decision Tree, Random Forest, Gradient Boosting, SVR, and KNN.

## Classification

Smartphone price-category classification using supervised machine learning.

## Clustering

Smartphone data clustering using K-Means and Agglomerative Hierarchical
Clustering.
